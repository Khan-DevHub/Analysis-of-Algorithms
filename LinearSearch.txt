Algorithm:
    i = 0

    for (i = 0; i < n; i++)
    {
        if (arr[i] == key)
        {
            printf("Found");
        }
    }

Analysis:
    Step 1:
        i = 0
        This is an initialization statement.
        It runs 1 time.

    Step 2:
        The loop condition i < n
        is checked n + 1 times.

    Step 3:
        The if condition
        arr[i] == key
        runs n times because it is inside the loop.

    Step 4:
        printf("Found")
        is a constant operation.
        It is counted as 1 time.

    Step 5:
        Add all the main terms:

        1 + (n + 1) + n + 1

        = 2n + 3

    Step 6:
        Ignore the constants 2 and 3.

        2n + 3
        = O(n)

Final Time Complexity:
O(n)
