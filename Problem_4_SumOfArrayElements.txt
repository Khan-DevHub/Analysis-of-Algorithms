Algorithm:
    Sum(arr, n)

    sum = 0;

    for(i = 0; i < n; i++)
    {
        sum = sum + arr[i];
    }

    return 0;

Analysis:

    Step 1:
        sum = 0
        This statement runs 1 time.

        Count = 1


    Step 2:
        i = 0
        This is the initialization part of the for loop.
        It runs 1 time.

        Count = 1


    Step 3:
        i < n
        This is the loop condition.

        The condition is checked n + 1 times
        because it is checked one extra time when
        the loop becomes false.

        Count = n + 1


    Step 4:
        i++
        This is the increment part of the for loop.

        It runs n times because the loop body
        executes n times.

        Count = n


    Step 5:
        sum = sum + arr[i]
        This statement is inside the loop.

        The loop runs n times, so this statement
        also runs n times.

        Count = n


    Step 6:
        return 0
        This statement runs 1 time.

        Count = 1


    Step 7:
        Add all the step counts:

        1 + 1 + (n + 1) + n + n + 1

        = 3n + 4


    Step 8:
        Ignore the constant terms.

        3n + 4
        = O(n)


Final Step Count:
    3n + 4


Final Time Complexity:
    O(n)


Space Complexity:
    O(n) if the input array arr is included.

Auxiliary Space Complexity:
    O(1)
