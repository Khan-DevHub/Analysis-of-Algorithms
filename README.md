# 📊 Analysis of Algorithms

A daily practice repository focused on learning, analyzing, and understanding algorithms through step-by-step problem solving.

## 📖 About This Repository

This repository contains my regular practice for the **Analysis of Algorithms** course. The main goal is to develop a strong understanding of how algorithms work and how their efficiency can be analyzed.

For each problem, I break the algorithm down into simple steps, identify repeated operations, calculate their frequency, and determine the overall time complexity using **Big-O notation**.

This repository also serves as a record of my daily practice, learning, and progress in algorithm analysis.

## 🎯 Objectives

The main objectives of this repository are:

- Practice algorithms consistently on a daily basis.
- Understand how different algorithms work.
- Break algorithms into smaller and easier steps.
- Identify the number of times each operation is performed.
- Analyze loops and nested loops.
- Calculate operation counts.
- Understand how input size affects algorithm performance.
- Determine time complexity using Big-O notation.
- Improve problem-solving and analytical skills.
- Build a strong foundation in algorithm analysis.

## 💡 Time Complexity

The main focus of this repository is understanding how the running time of an algorithm grows as the input size increases.

Some common time complexities include:

| Complexity | Name |
|------------|------|
| `O(1)` | Constant |
| `O(log n)` | Logarithmic |
| `O(n)` | Linear |
| `O(n log n)` | Linearithmic |
| `O(n²)` | Quadratic |
| `O(2ⁿ)` | Exponential |

The goal is not only to identify the final Big-O notation but also to understand **why** an algorithm has that complexity.
