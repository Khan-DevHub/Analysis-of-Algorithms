Algorithm:
    for(i = 0; i < n; i++)
    {
        for(j = 0; j < n; j++)
        {
            a = b + c;
        }
    }

Analysis:
    Outer Loop:
    i = 0 → 1
    i < n → n + 1
    i++ → n

    Inner Loop:
    j = 0 → n
    j < n → n(n + 1)
    j++ → n²

    Main Operation:
    a = b + c → n²

Total Step Count:
    1 + (n + 1) + n + n + (n² + n) + n² + n²
    = 3n² + 4n + 2

Final Step Count:
    3n² + 4n + 2

Final Time Complexity:
    O(n²)
