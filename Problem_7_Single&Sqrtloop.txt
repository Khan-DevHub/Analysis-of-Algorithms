Algorithm:

    for(i = 0; i < n; i++)
    {
        a = b + c;
    }
    p = 0
    for(i = 1; p <= n; i++)
    {
        p = p + i;
    }


Analysis:

    First Loop:
    i = 0 → 1
    i < n → n + 1
    i++ → n
    a = b + c → n

    Second Loop:
    p = 0 → 1
    i = 1 → 1
    p <= n → k + 1  or p <= n → √n + 1
    i++ → k or i++ → √n
    p = p + i → k or p = p + i → √n

    Where:
    1 + 2 + 3 + ... + k ≤ n
    k(k + 1) / 2 ≤ n
    Therefore:
    k = Θ(√n)

Total Step Count:

    First Loop:
    1 + (n + 1) + n + n
    = 3n + 2

    Second Loop:
    1 + 1 + (k + 1) + k + k
    = 3k + 3

    Since k = Θ(√n):

    Total = 3n + 3√n + constant

Final Time Complexity:
    O(n)

Important:

    The first loop is O(n).
    The second loop is O(√n).

    Since both loops are sequential:

    O(n) + O(√n)
    = O(n)
