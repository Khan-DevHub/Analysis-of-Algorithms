Problem: Addition of Two Arrays

Algorithm:
    ArraySum(arr1, arr2, n)

    arr3 = {0};

    for(i = 0; i < n; i++)
    {
        for(j = 0; j < n; j++)
        {
            arr3(i,j) = arr1(i,j) + arr2(i,j);
        }
    }

    return 0;

Analysis:

    Step 1:
        arr3 = {0}
        This is an initialization statement.
        It runs 1 time.

        Count = 1


    Step 2:
        Outer loop initialization:
        i = 0

        It runs 1 time.

        Count = 1


    Step 3:
        Outer loop condition:
        i < n

        It is checked n + 1 times.

        Count = n + 1


    Step 4:
        Outer loop increment:
        i++

        It runs n times.

        Count = n


    Step 5:
        Inner loop initialization:
        j = 0

        It runs n times because the inner loop
        starts once for every outer loop iteration.

        Count = n


    Step 6:
        Inner loop condition:
        j < n

        It is checked n + 1 times for each
        outer loop iteration.

        Therefore:

        n × (n + 1)
        = n² + n

        Count = n² + n


    Step 7:
        Inner loop increment:
        j++

        It runs n times for each outer loop iteration.

        Therefore:

        n × n
        = n²

        Count = n²


    Step 8:
        arr3(i,j) = arr1(i,j) + arr2(i,j)

        This statement is inside the inner loop.

        The inner loop runs n times for each
        outer loop iteration.

        Therefore:

        n × n
        = n²

        Count = n²


    Step 9:
        return 0

        This statement runs 1 time.

        Count = 1


    Step 10:
        Add all the step counts:

        1 + 1 + (n + 1) + n + n + (n² + n) + n² + n² + 1

        = 3n² + 4n + 4


    Step 11:
        Ignore constants and lower-order terms.

        3n² + 4n + 4
        = O(n²)


Final Step Count:
    3n² + 4n + 4


Final Time Complexity:
    O(n²)


Space Complexity:
    O(n)
