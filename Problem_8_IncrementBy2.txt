Algorithm:
    for(i = 1; i < n; i = i + 2)
    {
        a = b + c;
    }

Analysis:
    i = 1 → 1
    i < n → n/2 + 1
    i = i + 2 → n/2
    a = b + c → n/2

Why n/2?
    i = 1
    i = 3
    i = 5
    i = 7
    i = 9
    ...

The value of i increases by 2 in every iteration. Therefore, to reach n, the loop runs approximately n/2 times.

Total Step Count:
    1 + (n/2 + 1) + n/2 + n/2
    = 3n/2 + 2

Final Step Count:
    3n/2 + 2

Final Time Complexity:
    O(n)
